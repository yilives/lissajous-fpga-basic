# 李萨如图形显示控制装置：FPGA 基础部分

本工程整理自 2026 年电赛赛区赛 F 题的 FPGA 实验版本。它接收正弦输入，经 ADC 测量、数字锁相和 DDS 合成后，通过 DAC 产生示波器 Y 轴信号，供 X-Y 模式显示李萨如图形。工程主要面向题目第 1～4 项；摄像头、上位机视觉处理和第 5 项完整闭环不在本仓库中。

> 这是实验工程，并非所有频点和竞赛指标均已验证通过。线模式由 ADC 测量后重新合成，不能等同于物理模拟直通；低幅值锁相、相位及幅度精度需要在实际硬件上验证和校准。

## 功能与操作

板载 S4（IO87，低有效）依次切换以下模式，上电默认模式 1：

| 模式 | 目标输出 | 示波器 X-Y 图形 |
| --- | --- | --- |
| 1 | 与输入同频、同相、等幅的重建波形 | 对角线 |
| 2 | 同频、相差 90°、等幅 | 圆或椭圆 |
| 3 | 二倍频、等幅 | ∞ |
| 4～7 | 二倍频，输出高度依次约 2、4、6、8 div | ∞ |

幅度档位按示波器 0.5 V/div 设计，模拟链路的实际增益决定最终结果。S3（IO85）切换 UART2 的外部控制权；协议见 [UART2_PC_DDS_PROTOCOL.md](UART2_PC_DDS_PROTOCOL.md)。该接口不代表本仓库包含完整视觉系统。

数据通路：`ADC → 幅度/周期估计 → 块 I/Q 相位与频率跟踪 → DDS → DAC`。ADC 和 DAC 工作时钟均为 25 MHz，板载参考时钟为 50 MHz；器件为 Cyclone IV E `EP4CE22E22C8`。

## 硬件连接

| 信号 | FPGA 管脚 |
| --- | --- |
| 50 MHz 时钟 | 24 |
| ADC D0～D9 | 77, 76, 72, 71, 69, 68, 67, 66, 65, 64 |
| ADC CLK / OE / OTR | 58 / 59 / 60 |
| AD9764 D0～D13 | 100, 99, 103, 101, 105, 104, 110, 106, 112, 111, 114, 113, 119, 115 |
| AD9764 CLK | 121 |
| S3 / S4 | 85 / 87 |
| SSD1306 OLED SCL / SDA | 142 / 144 |
| UART1 TX / RX | 141 / 143 |
| UART2 TX / RX | 133 / 136 |

完整约束以 `ad9226_ad9764_test.qsf` 和 `ad9226_ad9764_test.sdc` 为准。IO83 在原硬件上接地并配置为输入；使用其他板卡前必须检查接线、电平、管脚和时序。UART 使用 3.3 V 电平，共地，115200 8N1。

## 编译和使用

1. 安装 Intel Quartus Prime 18.1 Standard（工程原配置），打开 `ad9226_ad9764_test.qpf`。
2. 检查器件、管脚分配及 SDC 与自己的硬件一致，然后执行完整编译。
3. 使用 Programmer 下载生成的 `output_files/ad9226_ad9764_test.sof`，连接信号源、ADC、DAC 和示波器进行测试。
4. 从低频、适当幅度开始检查采样和波形，再验证 1 kHz～100 kHz 范围内的模式与指标。工程中的 `DAC_GAIN_Q10`、`DAC_DC_TRIM_CODES`、相位和路径延迟参数针对原实验硬件，应根据实测重新标定。

SDC 对 ADC 输入捕获路径使用了 false path；编译时序通过不能单独证明外部 ADC 总线采样可靠，需结合器件时序和实际波形验证。修改时钟、板卡或约束后尤其如此。

整理后的工程在 Quartus Prime 18.1 Standard 完整编译成功，但产生多项警告，时序分析器提示设计未完全约束；本次未进行硬件复测或完整 RTL 仿真。

## 主要文件

- `ad9226_ad9764_top.v`：顶层、采样控制、模式选择与 DDS。
- `adc_block_iq_pll.v`：块 I/Q 相关和相位/频率跟踪。
- `conv_clk_10m_pll.v`：基于 Intel `altpll` 的时钟封装。
- `reference_sin_rom1024.v`、`sin_1024x14.hex`：正弦查找表及同步 ROM；`generate_sine_table.py` 可重新生成 HEX 和供查看的 MIF。该表与原实验表略有差异，需重新上板校准。
- `i2c_master.v`、`ssd1306_oled.v`、`font_8x16.v`：OLED 显示。字体只覆盖当前状态显示所需字符。
- `uart*.v`：串口收发与控制。
- `ad9226_ad9764_test.qpf/.qsf/.sdc`：Quartus 工程、管脚和时序约束。

工程不包含编译缓存、烧录文件、题目原文、器件手册及外部参考工程。本仓库代码按 [MIT 许可证](LICENSE)发布；Intel Quartus 和器件原语依各自供应商条款使用。
